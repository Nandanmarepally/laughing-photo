Project Plan
1. Talking Photo Application
Tech Stack:

Frontend: React.js (with CSS for styling)
Backend: Node.js, Express.js
API: Vidnoz Talking Avatar API 
2. Text-to-Avatar Application
Tech Stack:

Frontend: React.js
Backend: Node.js, Express.js
API: Vidnoz Text-to-Avatar API

Project Execution Steps
Setup Project Structure

Create a monorepo with two projects (frontend + backend).
Install dependencies (npm install react node express axios cors dotenv).
Setup .env files for API keys.
Frontend Development (React.js)

Build UI components for file uploads, text inputs, and API interaction.
Implement state management and error handling.
Add responsive styling.
Backend Development (Node.js + Express.js)

Create API endpoints to communicate with Vidnoz OpenAPI.
Implement CORS handling and API key security.
Integration & Testing

Connect frontend with backend.
Ensure proper API response handling.
Test with sample images and text.
